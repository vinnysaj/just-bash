# @vinnysaj/just-bash-html

Adds the `html-to-markdown` command to [@vinnysaj/just-bash](https://github.com/vinnysaj/just-bash#readme), using [turndown](https://www.npmjs.com/package/turndown).

```sh
npm install @vinnysaj/just-bash @vinnysaj/just-bash-html
```

Without this package, `html-to-markdown` exits with status 127. Install the same version as `@vinnysaj/just-bash`. See the [main README](https://github.com/vinnysaj/just-bash#readme) for sizes and differences from upstream just-bash.
