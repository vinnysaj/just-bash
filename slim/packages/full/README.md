# @vinnysaj/just-bash-full

[@vinnysaj/just-bash](https://github.com/vinnysaj/just-bash#readme) with every add-on: python, js, sqlite, net, html, and archive. It re-exports core, so it is a drop-in replacement for upstream [just-bash](https://github.com/vercel-labs/just-bash) on Node.js.

```sh
npm install @vinnysaj/just-bash-full
```

```ts
import { Bash } from "@vinnysaj/just-bash-full";
```

See the [main README](https://github.com/vinnysaj/just-bash#readme) for sizes and differences from upstream just-bash.
