# @vinnysaj/just-bash-sqlite

Adds the `sqlite3` command to [@vinnysaj/just-bash](https://github.com/vinnysaj/just-bash#readme): SQLite compiled to WebAssembly, from [sql.js](https://www.npmjs.com/package/sql.js). Only the Node.js WebAssembly build of sql.js is included.

```sh
npm install @vinnysaj/just-bash @vinnysaj/just-bash-sqlite
```

Without this package, `sqlite3` exits with status 127. Install the same version as `@vinnysaj/just-bash`. See the [main README](https://github.com/vinnysaj/just-bash#readme) for sizes and differences from upstream just-bash.
